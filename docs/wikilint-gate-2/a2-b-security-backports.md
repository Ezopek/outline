## Behavioral qualification

Each author dependency slice has an executed failing regression before its package
change. Exact version assertions accompany behavioral negative and positive
controls; they do not replace those controls.

- **Markdown/YAML:** the actual converter retains ordinary aliased Markdown/text
  frontmatter and malformed-input behavior. A child process runs modest hostile
  multiline references and empty-merge sources through the real BaseConverter.
  The parent enforces a five-second wall deadline, 128 MiB V8 heap bound and
  64 KiB output cap. The patched converter treats over-budget YAML using its
  existing unchanged-source fallback. Real create and all four update projections
  cover canonical metadata, reference links, parse/serialize stability and an
  unchanged original document. The patch fixture spans blocks to exercise the
  baseline Markdown-reparse path; it does not redefine inline surgical patches.
- **ProseMirror:** DOM-backed shared tests use shipped heading/image attribute
  validators, forged slice contexts, valid copied context, external HTML paste,
  URL sanitization and a Yjs table/list/link round trip. The actual title component
  receives paste events for HTML, Markdown and forged context. jsdom's missing
  ClipboardEvent constructor is represented by a test-only Event for pasteHTML's
  supplied-payload API. No production schema or sanitizer is changed.
- **Engine.IO:** a loopback-only Socket.IO server at `/realtime` exercises the
  actual dependency edge. Missing/v3/v2 session-upgrade revisions return 400,
  leaving the valid v4 polling session intact. Invalid handshakes are refused;
  a real polling-to-WebSocket upgrade and a new session after disconnect succeed.
  Server/client cleanup and unexpected asynchronous errors are checked.
- **Mail:** offline JSON and stream transports cover recipient canonicalization,
  actual Mailer composition, reply/message/reference headers, the self-hosted logo,
  and actual MIME document import with a synthetic inline image. Root and nested
  module resolution are checked. A bounded child handles increasing address lists
  and malformed headers under the same wall/heap/output limits. No SMTP delivery
  occurs. The quoted-angle fixture distinguishes parser output from the composer's
  pre-existing angle-bracket-to-space normalization; both exact values retain the
  intended final domain. That normalization exists in both old and patched versions.

The author's clean parser slice passes 10 tests, shared clipboard passes 14 across its two
environments, title paste passes three, Engine.IO passes eight, and mail passes
eight. The author completed a sequential adversarial self-review; it is not
independent review or acceptance.
Synthetic resource probes establish bounded completion for these modest fixtures;
they do not prove asymptotic complexity or a production exploit. DOM tests use
jsdom, not a full browser end-to-end deployment.
