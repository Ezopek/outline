- (decision) Keep audit and MCP write enforcement in one initial implementation: deliver and validate audit first, add write-time prevention second, and call the implementation complete only after both pass acceptance.
- (decision) Primary users are agents operating through the standard Outline MCP endpoint; lint tools must give them unambiguous, machine-actionable feedback.
- (decision) Expected remediation loop: the linter reports deterministic findings; authorized agents safely fix what they can, re-lint until the clean-state criterion is met, and escalate only non-mechanical or decision-dependent findings.
- (decision) Define a clean batch as zero lint errors; warnings remain visible and optionally fixable but do not block completion or trigger an unbounded retry loop.
